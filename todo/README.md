# TODO — Organisation

Les tâches sont éclatées par **catégorie** (qui est concerné) puis par **type**.

Catégories :
- `fastfood/` — côté marchand (boutique, menus, images, gestion des commandes)
- `user/` — côté client (commande, panier, notifications, compte)
- `livraison/` — livraison, retrait, groupage, courses, livreurs
- `plateforme/` — global / transverse (versioning, validation, perfs, logs, outils dev)

Types de sous-dossiers :
- `bug/` — quelque chose ne fonctionne pas correctement
- `feature/` — nouvelle fonctionnalité ou gros changement de flux

Un fichier = une tâche, au format d'origine (`[ ]` + sous-puces). Les tâches
terminées sont archivées dans `_done.md`.

> Ancien fichier `.todo` : désormais un simple stub de redirection.
